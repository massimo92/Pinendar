# Gestión no es una agenda

Gestión se modela como una jornada telemática especial asociada a una persona y a una cuota mensual de uno a cinco días, no como demanda clínica. Dentro del modelo CP-SAT comparte las restricciones de ocupación con las agendas, pero conserva una ventana mensual flexible, no tiene hospital ni crea una plaza.

Su nivel efectivo queda por debajo de las agendas de prioridad muy alta y por encima de las prioridades alta, moderada y baja. El optimizador congela únicamente el valor óptimo de cada objetivo, nunca fechas, personas o vacantes concretas. Así puede mover Gestión y encadenar sustituciones para evitar cierres; solo deja una agenda no muy alta vacante cuando no existe una reorganización compatible con los objetivos superiores.

Después de cobertura y Gestión se minimizan las personas-día completamente sin actividad, se optimiza la equidad clínica y, como último criterio de negocio, se prefieren viernes, lunes y resto. Un asignador posterior codicioso no podría descubrir esas cadenas de sustitución ni comparar el resultado mensual completo.

Calendario, filtros, exportaciones e histórico la presentan junto a las agendas como una actividad planificada. Esa unión es de lectura: cobertura, vacantes, equidad clínica y felicidad conservan únicamente agendas clínicas; carga total, composición histórica y teletrabajo incluyen también Gestión.
